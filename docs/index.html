Local-first Agent Skill and CLI toolkit

Media Automation Lark

Collect RSS/API feeds, public web pages, local materials, and platform metrics into inspectable Markdown, JSON backups, and dashboards. Review the result locally before choosing whether to write to Feishu/Lark.

View latest release Open installable Skill

The project is a local workflow toolkit, not a hosted publishing platform. Network access and Feishu/Lark writes remain explicit and user-controlled.

What it covers

The runtime is designed for creators and small teams that need repeatable organization without hiding the review step.

  • Content archivingRSS/API items become structured records ready for review and optional Bitable writes.
  • Search collectionCollect public web results, categorize them, and preserve source links in Markdown.
  • Material managementBring articles, images, PDFs, and Office files into a local Markdown archive.
  • Metrics dashboardsBuild local HTML and Excel views from platform metrics with dry-run support.

Start from the source

Preview the Skill, install the runtime package, or run the offline demo before connecting credentials or public APIs.
