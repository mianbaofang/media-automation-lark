Media Automation Lark

把 RSS/API、公开网页、文件和平台指标整理成可检查的 Markdown、JSON 备份与看板；先在本地预览，再由你决定是否写入飞书。

查看公开版本查看可安装 Skill

这是一个本地工作流工具，不是代替用户做决定的托管发布平台。联网、远程抓取和飞书写入都必须由用户显式控制。

能做什么

适合需要重复整理内容、又不想跳过检查步骤的创作者和小团队。

内容归档

把 RSS/API 内容整理成记录，检查后再写入飞书多维表格。

搜索采集

收集公开网页结果、按规则分类，并在 Markdown 中保留来源链接。

素材管理

把文章、图片、PDF 和 Office 文件整理为本地 Markdown 素材库。

指标看板

用本地 HTML 和 Excel 查看平台指标，并支持 dry-run。

一分钟开始

先预览和安装 Skill，再运行不联网的内置样例：

gh skill preview mianbaofang/media-automation-lark media-automation-lark
gh skill install mianbaofang/media-automation-lark media-automation-lark --agent codex --scope user

python scripts/collector.py --offline-demo --output-dir output_demo --no-archive --no-notify --no-polish

当前公开版本为 v0.3.1。本地候选版本不会被页面写成已发布版本。

边界与资料

项目不绕过验证码、登录限制、付费墙、加密或平台风控。真实写入飞书前，请先使用 dry-run 和本地预览。
